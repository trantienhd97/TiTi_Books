# Supa Docs Site

This folder contains a minimal Docusaurus site for the Supa documentation.

Quick start:

```bash
cd /Users/tientv/Development/tientv/TiTiBooks/Supa/docs-site
# install deps
yarn install
# run dev
yarn start
# build
yarn build
```

Notes:
- The site's `docs/` are expected at `docs-site/docs/` (we copy them from the Supa `docs/`).
- Update `docusaurus.config.js` `url`, `organizationName`, and `projectName` before deploying.
